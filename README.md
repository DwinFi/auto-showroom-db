# Moto Showroom Database Project

## 📌 Описание проекта

Данный проект представляет собой информационную систему для управления базой данных мотосалона.  
Система позволяет работать с основными сущностями предметной области:

- мотоциклы
- производители
- категории
- клиенты
- менеджеры
- заказы
- позиции заказов

Проект реализован в виде веб-приложения и состоит из двух частей:

- серверной (Node.js + Express + PostgreSQL)
- клиентской (Vue.js)

Серверная часть обеспечивает обработку запросов и работу с базой данных, а клиентская часть предоставляет удобный графический интерфейс для пользователя.

---

## ⚙️ Используемые технологии

- Node.js
- Express.js
- PostgreSQL
- Sequelize ORM
- Docker
- Swagger (документация API)
- Vue.js (графический интерфейс)
- Vite (сборка frontend)
